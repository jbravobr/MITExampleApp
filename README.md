# Aplicativo MIT Infnet

> Aplicativo de trabalho do MIT em desenvolvimento de aplicações mobile, estruturado como solução Xamarin.Forms.

## Organização

- `AppTesteMITInfnet/` — projeto de testes.
- `Droid/` — projeto da plataforma Android.
- `iOS/` — projeto da plataforma iOS.

Solução: [`AppTesteMITInfnet.sln`](AppTesteMITInfnet.sln).

## Tecnologias

C#, Xamarin.Forms e projetos para Android e iOS.

## Como abrir

Abra [`AppTesteMITInfnet.sln`](AppTesteMITInfnet.sln) no ambiente de desenvolvimento compatível com a stack do projeto.
